# 盛り上がりファインダー

配信アーカイブの音声から盛り上がった場面を探し、切り抜きとYouTubeの目次づくりを手伝うブラウザツールです。

- **インストール不要。** GitHub Pages のページを開いて、動画を選ぶだけで使えます。
- **動画は外に出ません。** 解析も書き出しもブラウザの中だけで行い、どこにも送信しません。外部のライブラリやサーバーも使っていません。
- **長時間のアーカイブに対応。** MP4・MOV・MKV・WebM は動画を少しずつ読みながら音声だけを解析するため、数時間の動画でもメモリをほとんど使いません。

## できること

| 機能 | 内容 |
| --- | --- |
| 盛り上がりの検出 | 全体の音量と、人の声が多く含まれる帯域（300〜3000Hz）の音量を、直前1分間の基準と比べて候補を探します。配信の種類（雑談・実況／ゲーム音が大きい／歌・音楽）で判定の比重を切り替えられます。 |
| 候補の確認と編集 | 採用・不採用の判定、メモ、範囲の調整（タイムライン上のドラッグ、±1秒、現在位置で指定）、手動での追加・削除、範囲の繰り返し再生、採用分の通し再生。 |
| タイムライン | 拡大・縮小、ドラッグでの移動、全体表示から位置を移動。 |
| YouTubeの目次 | 採用した候補から概要欄用の目次を作ります。YouTubeの条件（0:00から始まる・3個以上・各10秒以上）を満たしていない場合は警告します。 |
| CSV | 候補の一覧を保存します（Excelで文字化けしないよう BOM 付き UTF-8）。 |
| ffmpegスクリプト | 手元の ffmpeg で切り抜くための .bat（Windows）／ .sh（Mac・Linux）を作ります。無劣化・高速、または再エンコードで正確な位置。縦型（9:16・1080×1920）にも対応します。 |
| ブラウザでの書き出し | ffmpeg が無くても、元の比率または縦型（9:16、切り取る位置を指定可）で切り抜き動画を保存できます。再生しながら録画する方式のため、切り抜きの長さと同じだけ時間がかかります。 |
| 作業の保存 | ブラウザに自動保存され、同じ動画を開くと復元されます。作業ファイル（JSON）として保存・読み込みもできます。 |

キーボード操作は画面右上の「?」から確認できます。

## 検出の仕組み

1. 0.1秒ごとに、全体の音量と声の帯域の音量を求め、1秒幅で平均します。
2. それぞれ「直前60秒間の中央値」を基準とし、基準より何dB大きいかを計算します。基準は過去の音だけで決まるため、無音から急に大きくなった場面も検出できます。
3. 配信の種類に応じた重みで2つを合わせ、「感度」を超えた区間を1つの盛り上がりとします。強さに、続いた長さ（最大8秒）を加えたものが総合スコアです。
4. スコアの高い順に、指定した最小間隔より近い候補を除いて並べます。候補の範囲は盛り上がりの始まりを基準に、前後へ指定の長さだけ広げます。

音量だけを見ているため、BGMや効果音で音が大きくなった場面も候補に入ります。最後は人の目で採用・不採用を決める前提の設計です。

## 対応形式

| 形式 | 解析の方式 |
| --- | --- |
| MP4・MOV（通常／断片化）、MKV・WebM で、音声が AAC・Opus・MP3 | 少しずつ読みながら解析（WebCodecs を使用） |
| 上記以外（WAV、MP3 単体など）や、ブラウザが WebCodecs に対応していない場合 | ファイル全体を読み込んで解析。長いファイルではメモリを多く使います |

実際に再生・解析できる形式は、使用するブラウザの対応状況にも左右されます。

## 動作確認の状況

ヘッドレス版 Chromium 141 で、次のことを確認しています。

- 10分のテスト動画（静かな所での叫び、無音から曲が始まる所、大音量のBGM中の声、最後の叫び、の4か所を仕込んだもの）で、4か所すべてを検出し、誤検出がないこと。WebM・MKV・MP4・断片化MP4（いずれも Opus）で同じ結果になること。
- 3時間の音声ファイルを約48秒で解析し、仕込んだ6か所をすべて検出すること。
- MP4・MKV・断片化MP4（AAC）から取り出した音声データの個数・合計サイズ・設定情報が、ffprobe の結果と一致すること。
- 生成した .sh スクリプトを実行し、無劣化の切り抜きと、縦型（1080×1920、H.264/AAC）への再エンコードが作られること。
- ブラウザでの書き出しで、縦型の WebM が音声付きで作られ、長さの情報も正しく入ること。
- 目次・CSV・作業の自動保存と復元。

次の項目は、テスト環境の制約により**未確認**です。

- **AAC 音声の復号。** テストに使った Chromium が AAC に対応していないため、確認できていません。配信アーカイブで一般的な MP4（H.264 + AAC）での解析が該当します。
- ブラウザ書き出しの MP4 形式（表示されるのは、ブラウザが対応している場合のみです）。
- Windows での .bat の実行。
- Chrome 以外のブラウザ（Edge・Safari・Firefox）での動作。

## 開発者向け

ビルドは不要です。ES モジュールとモジュールワーカーを使っているため、ローカルで試すときは `index.html` を直接開かず、簡易サーバー経由で開いてください（例: `python3 -m http.server`）。

```
index.html
css/style.css
js/app.js               画面と操作
js/analyzer-worker.js   解析（ワーカー）
js/demux.js             MP4・MKV・WebM から音声データを取り出す
js/detect.js            候補の検出
js/timeline.js          タイムラインの描画と操作
js/exporters.js         目次・CSV・ffmpegスクリプト
js/recorder.js          ブラウザでの動画書き出し
js/util.js              共通処理
```

## 切り抜きについての注意

他の方の配信を切り抜くときは、その配信者が定める切り抜きガイドラインに従ってください。
